# nimh_fy2025_ipids.csv

The 86 NIMH FY2025 annual-report ipids, extracted from `all_ics_2025_ipids.csv`
in https://github.com/nimh-dsst/irp_scraper (private), commit 3e56ec7, produced
by Josh Lawrimore in Jan/Feb 2026 for the publications scrape. That run covered
2,899 reports across 26 ICs and validated that every one carried the
"2025 Fiscal Year" heading.

Reusing that list avoids repeating the discovery step, which now requires
answering an arithmetic bot-check on the search form. If a future round needs a
fresh list, get a person to run the search rather than automating that check.

Prior rounds for comparison: FY2018 had 91 reports, FY2021 had 93.
