# Data directory notes

## External-partners map (FY2025 onward)

The map is generated by code — see "The external-partners map" in
[../ANALYSIS.md](../ANALYSIS.md). Its inputs live here:

- `institution_geocodes.csv` — committed geocode cache (Nominatim/OSM). Blank
  lat/lon rows are geocoder misses awaiting hand-filling; re-running
  `geocode_institutions.py` retries them.
- `ne_110m_land.geojson` — Natural Earth 110m land polygons (public domain),
  the basemap.
